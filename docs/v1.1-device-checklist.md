## 3. Reliability pass — the 3× rule (same command failing 3× = blocker)

Each command 3×, via mic (not text box):

| Command | Expect |
|---|---|
| "Mummy ko call karo" | dialer pre-filled with Mummy's number |
| "9876543210 pe call karo" | dialer pre-filled with the number |
| "Xyzabc ko call karo" (no such contact) | honest "contacts mein nahi mila" + empty dialer |
| "Raju ko whatsapp karo" | Raju's chat opens (wa.me) |
| "Raju ko message karo main late hoon" | chat opens with DRAFT pre-filled — VANI must NEVER auto-send |
| "Station ka rasta dikhao" | turn-by-turn or pin in Maps |
| "Paas mein ATM dhundho" | nearby search |
| Maps uninstalled/disabled edge | spoken "Maps nahi khul paya", no crash |

The wa.me draft flow was the suspected silent-failure: `https` was missing
from manifest `<queries>`, so `canLaunchUrl()` could return false and dump
users on the WhatsApp home screen. Fixed this branch — verify drafts now
pre-fill consistently.
